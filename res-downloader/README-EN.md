# res-downloader (with subtitle transcription)

This is the resource-sniffing/download core of the project, built on the open-source
[res-downloader](https://github.com/putyy/res-downloader) (Go + Wails, MIT) with local
ASR speech-to-subtitle transcription added on top.

See the repository root [README](../README.md) for full usage (portable build / from source / packaging).

> The base download capability comes from res-downloader under its open-source license (see `LICENSE`). For study and research only.
