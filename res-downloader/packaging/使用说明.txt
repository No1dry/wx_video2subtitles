res-downloader 便携版（含一键转录字幕）
==========================================

【怎么用】
1. 把本文件夹整个解压到任意位置（路径别带特殊字符即可）。
2. 双击 res-downloader.exe 启动。
3. 首次启动按提示「允许安装证书」并「允许网络访问」。
4. 首页左上角点「启动代理」，去对应 App/网页播放要下载的视频，回到软件即可看到资源列表。
5. 点某条资源的下载按钮（或勾选多条后「批量下载」）。

【转录字幕（无需安装 Python，已内置）】
1. 视频下载完成后，点该行的操作菜单 →「转录字幕」；或勾选多条后用「批量转录」。
2. 选字幕格式（SRT / TXT / 两者）和语言，点「开始转录」。
3. 进度条会实时显示百分比；完成后提示字幕路径，可点「打开字幕」。
4. 字幕默认保存在视频所在目录的 subtitles 子文件夹里。
   （可在「设置 → 转录设置 → 字幕保存目录」改成固定文件夹。）

【CPU 版 / GPU 版的区别】
- CPU 版：任何 Windows 电脑都能用，无需显卡；转录速度一般。
- GPU 版：电脑有 NVIDIA 显卡时自动用显卡加速（快很多）；没有显卡会自动回退到 CPU。
  GPU 版体积更大（内置了 CUDA 库）。

【常见问题】
- 转录一直不动 / 报错：确认整个文件夹是完整解压的（transcriber 文件夹和 models 文件夹都在）。
- 想要更准的字幕：转录较慢但更准的模型需要单独下载，详见 transcriber/models 说明或联系提供者。
- 关闭软件后无法上网：到系统代理设置里手动关闭代理。

【目录结构（请勿拆散）】
res-downloader.exe          主程序
transcriber\               转录引擎（内置 Python + 语音识别）
transcriber\models\        语音识别模型
使用说明.txt                本文件
